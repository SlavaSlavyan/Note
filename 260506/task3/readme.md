# Задание 3: Создать класс Array

Создайте класс **Array** (или используйте ранее созданный вами). 

Класс **Array** - это класс динамического массива. Размер массива может быть передан в качестве параметра или задан с помощью вызова функции-члена. Класс должен позволять заполнять массив значениями, отображать содержимое массива, изменять размер массива, сортировать массив, определять минимальное и максимальное значение. Класс должен содержать набор конструкторов (конструктор копирования обязателен), деструктор.

---

Я прям заебался с этим заданием, нооо мне в целом понравилось. Вот доступные методы у класса

- **int\* GetData()** - метод для прямого получения сырых данных.
- **int GetLength()** - метод для получения размера массива
- **int GetIndex(int i)** - метод для получения отдельного элемента внутри массива
- **int Min()** - метод для получения минимального значения внутри массива
- **int Max()** - метод для получения максимального значения внутри массива
- **Array& Set(int data, int id)** - метод для изменения отдельного элемента внутри массива
- **Array& Add(int data)** - метод для добавления нового элемента массива в конец
- **Array& Insert(int data, int id)** - метод для добавления нового элемента массива в определёный индекс
- **Array& Remove(int id)** - метод для удаления элементов
- **Array& Swap(int i1, int i2)** - метод для перестановки двух элементов
- **Array& Sort()** - метод для сортировки массива
- **Array& Reverse()** - метод для реверса массива
- **Array& Clear()** - метод для очистки массива
- **Array& Print()** - метод для вывода массива
