# Задание 2: Класс String

Разработать класс **String**, который в дальнейшем будет использоваться для работы со строками.

### Класс должен содержать:

- Коструктор по умолчанию, позволяющий создать строку длинной **80** символов;
- Коструктор, позволяющий создавать строку произвольного размера;
- Конструктор, который создаёт строку и инициализирует её строкой, полученной от пользователя;
- Конструктор копирования;

Класс должен содержать методы для ввода строк с клавиатуры и вывода строк на экран.

Точка входа [**start.cpp**](./start.cpp), включает в себя реализацию класса [**MyString.cpp**](./src/MyString.cpp) с интерфейсом [**MyString.hpp**](./include/MyString.hpp).
