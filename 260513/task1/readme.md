## Задание 1.1 (Базовое) - Класс Fraction

Создайте класс **Fraction** для работы с обыкновенными дробями (числитель/знаменатель). Перегрузите операторы:
- +, -, *, / для арифметических операций
- ==, !=, <, > для сравнения
- << и >> для ввода/вывода

### Требования:

- Дробь всегда должна храниться в сокращённом виде
- Знаменатель всегда положительный
- Обработка деления на ноль (выбросить исключение)

### Пример использования:

```cpp
Fraction a(1, 2); // 1/2
Fraction b(3, 4); // 3/4
Fraction c = a + b; // 5/4
cout << c; // Вывод: 5/4
```

## Задание 1.2 (Среднее) - Класс Vector3D

Создайте класс **Vector3D** для работы с трёхмерными векторами. Перегрузите:

- +, - (векторная сумма/разность)
- \* (скалярное произведение с другим вектором и умножение на скаляр)
- ++ (префиксный и постфиксный инкремент - увеличение всех координат на 1)
- [] (доступ к координатам по индексу 0,1,2)
- +=, -=, *=

**Дополнительно:** Создайте статический метод для подсчёта количества созданных векторов.

## Задание 1.3 (Продвинутое) - Класс Matrix

Создайте шаблонный класс **Matrix\<T>** для работы с матрицами (размер задаётся в конструкторе). Перегрузите:

- +, -, * (сложение, вычитание, умножение матриц)
- \* (умножение матрицы на скаляр)
- () (доступ к элементу: **matrix(i,j)**)
- ! (транспонирование матрицы)
- = (присваивание с глубоким копированием)
- ==, != (сравнение матриц)

### Требования:

- Динамическое выделение памяти 
- Правило трёх (конструктор копирования, оператор присваивания, деструктор)
- Проверка совместимости размеров для операций
