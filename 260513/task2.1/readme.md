# НАСЛЕДОВАНИЕ

## Задание 2.1 (Базовое) - Иерархия геометрических фигур

Создайте иерархию классов:

- Базовый класс **Shape** с чисто виртуальными методами:

    - **double area() const** (площадь)
    - **double perimeter() const** (периметр)
    - **void print() const** (вывод информации)

- Производные: **Circle** , **Rectangle** , **Triangle**

### Требования:

- В каждом классе свой конструктор с параметрами
- Переопределение виртуальных методов
- Виртуальный деструктор
- В базовом классе добавить статический член для подсчёта фигур

### Пример:

``` cpp
Shape* shapes[] = {new Circle(5), new Rectangle(3,4)};
cout << shapes[0]->area(); // π*25
```
