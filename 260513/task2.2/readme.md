# НАСЛЕДОВАНИЕ

## Задание 2.2 (Среднее) - Иерархия сотрудников

Создайте иерархию:

- Базовый класс **Employee** с полями: имя, ID, базовая зарплата

    - Виртуальный метод **calculateSalary()** (возвращает базовую)

    - Виртуальный метод **getInfo()**

    - **Manager** (добавляет: бонус в процентах, количество подчинённых)
        - Переопределяет **calculateSalary()** : базовая + бонус * 100 за каждого подчинённого

    - **Developer** (добавляет: язык программирования, опыт в годах)
        - Переопределяет **calculateSalary()** : базовая + опыт * 5000
        
    - **Intern** (добавляет: наличие наставника)
        - Переопределяет **calculateSalary()** : 70% от базовой

**Дополнительно**: Создайте класс **Department**, который хранит список сотрудников и может:

- Добавлять/удалять сотрудников
- Подсчитывать общую зарплату
- Находить сотрудника с максимальной зарплатой
- Сортировать сотрудников по зарплате
