### Материнская плата

Важные элементы:
* Сокет
* Чипсет (это набор микросхем управляющих связью между центральным процессором, памятью и накопителями)
* Слоты памяти для оперативной памяти
* Форм факторы (физический размер материнской памяти)
	* ATX
	* Micro-ATX
	* Mini-ITX
### Типы интерфейсов и принципы организации используемых в компьютерных сетях

1. Параллельный:
	* Принцип передачи: несколько бит передаются одновременно по нескольким линиям
2. Последовательный:
	* Принцип передачи: биты передаются один за другим по одной линии
	* Самая популярная
3. Радиальное
	* Связь одного центрального устройства с несколькими другими периферийными устройствами
### Корпус ПК

Служит для защиты от грязи, для размещения компонентов и для правильного охлаждения

Форм факторы:
* Full Tower - ATX, E-ATX
* Mid Tower - Micro-ATX, ATX, Mini-ITX
* Mini Tower - Mini-ITX, Micro-ATX
### Блок питания

Форм факторы:
- ATX - Full Tower, Mid-Tower (самый распространённый)
- SFX - Mini-ITX, Micro-ATX
- Flex-ATX (уменьшенный ATX)
- EPS (медицинские\промышленные оборудования)
### Шины

Шина - это набор электрических линий по которой передаются данные между центральным процессором, памятью и накопителями

Есть 2 вида:
1. DMA - это прямой доступ к памяти
2. БЕЗ DMA - идёт через процессор
