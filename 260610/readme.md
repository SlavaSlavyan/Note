## Ответы на вопросы

### 1. Перегрузка методов. Можно ли сделать перегруженный конструктор?

Перегрузка методов заключаетсяв том что мы можем создать несколько разных функций с одним именем, но с разными аргументами. Тоже самое можно мделать не только с методами, но и с Конструкторами.

```cpp
class Template {

    int num;

public:
    
    // базовый конструктор
    Template() { num = 0; }

    // конструктор с аргументами
    Template(int n) : num(n) {}

    // конструктор копирования
    Template(const Template& other) : Template(other.num) {}
};
```

обычно как раз делают 3 конструктора - **базовый, с аргументами и копирование**

### 2. Как получить доступ к приватному полю из другого класса?

Смотря где ты находишься. Если ты находишься в методе самого класса, то для этого обычно нужно лишь указать само название переменной.

Иногда бывает что локальная переменная внутри метода может иметь тоже имя что и приватная. Чтобы их различать есть особое спец имя `this`

```cpp 
this->name;
```

Ну а если мы находимся вне класса и хотим получить переменную, то надо уже создавать дополнительные методы называемыми **геттерами** и **сеттерами** (ну а сама такая переменная будет называтся **Свойством**)

```cpp
class Template {

    // находится в private
    int num = 0;

public:

    // геттер
    int getNum() { return num; }

    // сеттер
    void setNum(int n) { num = n; }s
};
```

это позволяет реализовать принципп ООП - **инкапсуляция**

### 3. Что такое переопределение метода (override)

Если кратко, то у нас есть базовый класс `Template` с методом `print`. Мы решили сделать наследника `SmartTemplate` который будет круче первого. Все дочерние классы наследую все методы из материнского, но что делать если нам не нравится какой либо оригинальынй метод? Мы можем его переопределить, по сути заново написав его в дочернем классе. Теперь наш новый класс сможет делать старые вещи по новому.
