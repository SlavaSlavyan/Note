# Задание 6. Что означает константная функция

Константная функция это метод класса, которая не изменяет внутрянку класса и не вызывает другие неконстантные методы класса

вот как выглядит 

```cpp
class MyClass {
private:
    int value;
public:
    // Константный метод
    int getValue() const {
        // value = 5; // Ошибка компиляции: нельзя менять поля
        return value;
    }
    
    // Обычный метод
    void setValue(int v) {
        value = v; 
    }
};
```
