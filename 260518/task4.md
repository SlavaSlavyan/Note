# Задание 4. Может ли быть в классе несколько конструкторов? Почему?

Да.

Если подробнее, то в классе действительно может существовать несколько конструкторов как минимум потому что их существует 3 разных вида которые выполняют разные функции *([см задание 3](./task3.md))*

А так же существуют задачи когда нужно передавать разные аргументы в разные экземпляры.

Компилятор не запутается так как конструкторы отличаются сигнатурами - наборами передаваемых аргументов.

Вот вам ещё пример реализации потомушо чат джбт бесплатный ☜(ﾟヮﾟ☜)

```cpp
#include <iostream>
#include <string>

class Student {
private:
    std::string name;
    int age;

public:
    // 1. Конструктор по умолчанию
    Student() {
        name = "Неизвестно";
        age = 0;
    }

    // 2. Конструктор с параметрами
    Student(std::string studentName, int studentAge) {
        name = studentName;
        age = studentAge;
    }

    void printInfo() {
        std::cout << "Имя: " << name << ", Возраст: " << age << std::endl;
    }
};

int main() {
    Student s1;                  // Вызов конструктора 1
    Student s2("Алексей", 20);   // Вызов конструктора 2

    s1.printInfo(); // Выведет: Имя: Неизвестно, Возраст: 0
    s2.printInfo(); // Выведет: Имя: Алексей, Возраст: 20

    return 0;
}
```
