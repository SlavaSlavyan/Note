# Задание 3. Что такое конструктор

При создании класса, если мы хотим создать его экземпляр всегда вызывается особая функция-член - **конструктор**. Его главная функция это инициализация полей и выделение памяти, но так же он может выполнять и дополнительные функции. Изначально он пустой, но мы можем его переписать.

Обычно выделяют **3** типа конструкторов

## 1. Конструктор по умолчанию

Существует **ВСЕГДА ПО УМОЛЧАНИЮ** и вызывается когда мы создаём обьект без параметров. 

```cpp
#include <iostream>
using namespace std;

class Point {
private:
    int x, y;
public:
    // Конструктор по умолчанию
    Point() {
        x = 0;
        y = 0;
    }
    void print() { cout << "X: " << x << ", Y: " << y << endl; }
};

int main() {
    Point p1; // Автоматически вызывается конструктор по умолчанию
    p1.print(); // Выведет: X: 0, Y: 0
    return 0;
}
```

## 2. Конструктор с параметрами

Иногда нужно создавать обьекты с какими-то параметрами. Для этого подойдёт подобный конструктор.

```cpp
#include <iostream>
using namespace std;

class Point {
private:
    int x, y;
public:
    // Конструктор с параметрами
    Point(int startX, int startY) {
        x = startX;
        y = startY;
    }
    void print() { cout << "X: " << x << ", Y: " << y << endl; }
};

int main() {
    Point p2(10, 20); // Передаем аргументы в конструктор
    p2.print(); // Выведет: X: 10, Y: 20
    return 0;
}
```

## 3. Конструктор копирования

Особый конструктор который позволяет скопировать информацию из другого класса. Так же существует **ВСЕГДА**! Переписывать его стоит в случае выделения динамической памяти, так как такой конструктор копирует информацию побитово *(или побайтово я не помню)*.

```cpp
#include <iostream>
using namespace std;

class Point {
private:
    int x, y;
public:
    Point(int x, int y) : x(x), y(y) {} // Используем список инициализации

    // Конструктор копирования
    Point(const Point &obj) {
        x = obj.x;
        y = obj.y;
    }
    void print() { cout << "X: " << x << ", Y: " << y << endl; }
};

int main() {
    Point p1(5, 5);
    Point p2 = p1; // Вызывается конструктор копирования
    p2.print(); // Выведет: X: 5, Y: 5
    return 0;
}
```

Ну и да, количество конструкторов внутри класса **НЕОГРАНИЧЕННО**
