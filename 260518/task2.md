# Задание 2. Понятие статичный метод и статичное поле

Для начала чё вообще такое так называемая **статика**? Обычно поля и методы класса находятся в экземпляре класса и никак не связанны с другими полями и методами из других экземпляров класса. Статика помогает нам создавать такие методы и поля которые хранятся не в отдельных экземплярах, а внутри самого класса. Такие члены класса можно вызвать без создания экземпляра. НО ВАЖНО!!! Статика не может на прямую взаимодействовать с НЕ статикой!

Вот вам ахуенски гиганский пример программы, которая показывает использование статики.

``` cpp
#include <iostream>

class GameCharacter {
private:
    std::string name;
    // Статичное поле: общее для всех объектов
    static int characterCount; 

public:
    GameCharacter(std::string charName) {
        name = charName;
        characterCount++; // Увеличиваем счетчик при создании нового объекта
    }

    ~GameCharacter() {
        characterCount--; // Уменьшаем счетчик при уничтожении объекта
    }

    // Статичный метод: может работать только со статическими полями
    static int getCharacterCount() {
        return characterCount;
    }

    void displayInfo() {
        std::cout << "Персонаж: " << name << std::endl;
    }
};

// Инициализация статичного поля (обязательно вне класса)
int GameCharacter::characterCount = 0;

int main() {
    std::cout << "Начальное количество: " << GameCharacter::getCharacterCount() << std::endl;

    GameCharacter hero1("Артас");
    GameCharacter hero2("Тралл");

    // Вызов статичного метода через класс (объект создавать не нужно)
    std::cout << "Текущее количество: " << GameCharacter::getCharacterCount() << std::endl;

    hero1.displayInfo();
    hero2.displayInfo();

    return 0;
}
```

Тут мы сделали статический счётчик всех созданных героев. Кстати в новых версиях С++ не обязательно отделять инициализацию статического поля от самого класса, так как появился `inline`.
