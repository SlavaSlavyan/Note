Когда вы открываете любую программу, ОС создаёт процесс для данного приложения. Этот процесс помнит какой файл вы открыли, его данные, какие функции выполняет приложение.

Для запуска программы через командную строчку нужно ввести `start <название программы>`.

**Иерархия процессов** - это структура которая показывает взаимосвязь между различными процессами, образующими дерево.
### Основные понятия иерархии процессов

**Процесс основа** - это процесс который запускает ОС
**Родительский процесс** - это процесс который порождает другие процессы (дочерние процессы) и может управлять их жизненным циклом.
**Дочерний процесс** - это процесс созданный родителем. Наследует его атрибуты, но так же может быть независимым, выполнять свои задачи, стать родителем создав дочерний элемент.

У каждого процесса есть уникальный PID
**PID** - это числовой код (идентификатор процесса), который система назначает каждому активному процессу
Команда `tasklist` позволяет вывести список всех процессов и их PID.
Команда `tackkill <аргументы>` позволяет завершать процессы. Аргументы могут быть разными (`/PID <pid процесса>`,`/IM <название программы>`)
