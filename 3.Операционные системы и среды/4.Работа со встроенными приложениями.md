**Встроенные приложения** - это специализированные программные обеспечения, интегрированные в ОС.

Виды встроенных приложений:
1. Встроенные системные программы - это набор программ, которые управляют аппаратными ресурсами компьютера, и представляют основные функциональные возможности для других программ;
2. Встроенные прикладные программы - это программы которые выполняют конкретные задачи для пользователя, и помогают ему решать повседневные проблемы;

Список встроенных приложений и утилит для Windows 10 и Windows 11:
* Проводник;
* Панель управления;
* Параметры;
* Блокнот;
* Календарь;
* Калькулятор;
* Почта;
* Камера;
* Фотографии;
* Диспетчер задач;
* Браузер Microsoft Edge;
* Microsoft Store;
* Плееры;
* Прослушивание музыки;
* Центр безопасности защиты Windows;
* Диск восстановления и резервное копирование;
* Дефрагментация диска;
* Средство проверки памяти Windows;
* Командная строчка;
* Средство записи звука;
* Ножницы;
