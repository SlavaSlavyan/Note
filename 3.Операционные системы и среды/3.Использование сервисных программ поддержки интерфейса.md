Это применение программных продуктов, которые расширяют возможности ОС и предоставляют пользователю дополнительные услуги в работе с компьютером. Такие программы (утилиты) могут быть предназначены для обслуживания работы компьютера и улучшения пользовательского интерфейса, а так же автоматизации процессов.

Некоторые виды сервисных программ поддержки интерфейса:
1. Программа оболочки - это надстройки над ОС. Представляют новый интерфейс, делают необязательные знания ОС. ОС Windows использует оболочку FAR (Far manager).
2. Утилиты - они автоматизируют выполнение типовых, часто используемых процедур, реализация которых потребовала бы от пользователя дополнительных знаний
3. Программы для работы с дисками - обеспечивают проверку работоспособности, структурирования, дефрагментацию.
4. Программы для выявления неисправностей - они следят за работой системных компонентов, диагностируют и готовят отсчёты об аппаратных неисправностях, а так же обнаруживают системные ошибки и восстанавливают систему.

Безопасность при использовании сервисных программ поддержки интерфейсов, важно учитывать:
1. Шифрование данных - конфиденциальные данные, которые обмениваются, должны быть зашифрованы.
2. Строгая аутентификация - механизмы строгой аутентификация ограничивают несанкционированный доступ к пользовательским данным.
3. Соблюдение принципа "наименьшей привилегии" - пользователем и компонентам предоставляется только минимальный доступ и разрешения, необходимый им для выполнения задач
