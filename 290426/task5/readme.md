# Задача 5: «Термометр» (Перегруженные конструкторы) 

### Условие: 

Создайте класс **Thermometer** для измерения температуры. Класс должен иметь несколько конструкторов **(перегрузка)**

### Задание: 

1. Создайте класс **Thermometer** со скрытыми полями:

    - **double celsius** — температура в градусах Цельсия 
    - **char\* location** — место измерения (например, "Улица", "Комната")

2. Реализуйте три перегруженных конструктора: 

    - Конструктор по умолчанию (без параметров) — устанавливает **celsius** = 0.0, **location** = "Неизвестно" 
    - Конструктор с одним параметром: **Thermometer(double tempCelsius)**. Устанавливает переданную температуру, **location** = "Неизвестно" 
    - Конструктор с двумя параметрами: **Thermometer(const char\* place, double tempCelsius)**. Устанавливает и место, и температуру

3. Реализуйте методы: 

    - **double getCelsius()** — возвращает температуру в Цельсиях 
    - **double getFahrenheit()** — переводит и возвращает в Фаренгейты  *(F = C * 9/5 + 32)*
    - **void printInfo()** — выводит информацию 

4. В **main()** создайте три объекта, используя каждый из трёх конструкторов, и выведите информацию о каждом.
