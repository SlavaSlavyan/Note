Так как я работаю с VScode, а не Visual Studio мне необходимо настраивать компилятор вручную.

Решение для меня простое, для того тобы данная программа запустилась необходимо сделать несколько вещей.

*(можно сказать что это инструкция лично для меня)*

## 1. Правильное написание файлов

Для того чтобы создать класс в с++ нам нужно минимум 2 файла. У меня все доп файлы будут находится в папке **src**, и все заголовки в **include**.

В файлах заголовках никаких других путей не указыватеся, так что работа с путями важна только в остальных файлах.

Наш основной файл *(точка входа)* в начальном положении уже видит папку include, так что чтобы дотяуться до заголовка нужно лишь указать папку.

`#include "include\TestClass.hpp"`

Всё просто, но важно учесть для файлов которые находятся например в соседствующей папке src, что нужно указывать путь до include ОТНОСИТЕЛЬНО ЭТОЙ ПАПКИ. Немного непонятно, но если проще нам необходимо спуститься ниже на директорию.

`#include "../include/TestClass.hpp"`

Вот так. надеюсь этот текст хоть немного понятен.

## 2. Указать рабочие файлы

Настройки компилятора находятся в папке **.vscode/tasks.json**. Там их довольно много, но самое важное для нас это **args**

`"${file}"` внутри args указывает на то что мы компилируем файл из которого мы запускаем программу. Все остальные файлы компилятор не видит, так что их нам нужно указать вручную.

Вот как я указал наш класс: `"${workspaceFolder}/src/TestClass.cpp"`

Теперь все файлы указаны
