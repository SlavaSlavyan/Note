Представим что создаём БД для колледжа. 
Первое что нужно определить - это сущности:
* студенты
* специальность
* предметы
* препод
* оценка
* общий учебный план
* подробный учебный план с предметами
* группа

Так же нужно указать атрибуты:

Студент:
1. ID (SMALLINT)
2. ФИО (NVARCHAR(40-50) для каждого)
3. Группа (связь 1-N)
4. Пол CHAR(1)
5. Номер телефона (SMALLINT)
6. Почта (NCHAR(40-50)
7. Адрес
8. Когда родился
9. Дата поступления

Преподаватель:
1. ID (SMALLINT)
2. ФИО (NVARCHAR(40-50) для каждого)
3. Пол CHAR(1)
4. Номер телефона (SMALLINT)
5. Почта (NCHAR(40-50)
6. Адрес (NVARCHAR(40-50)
7. Когда родился (DATE)
8. Стаж работы (NVARCHAR(40-50)/(TINYINT)

Группа:
1. ID (SMALLINT)
2. Название (NVARCHAR(40-50))
3. ID специальности
4. Год набора (DATE)
5. Год выпуска (DATE)

Специальность:
1. ID (SMALLINT)
2. Код специальности (NCHAR(40-50))
3. Название (NVARCHAR(100))
4. Описание спец (TEXT прикрепляется файл)

Общий учебный план:
1. ID (SMALLINT)
2. Связь со специальтностью
3. Название учебного плана (NVARCHAR(40-50))
4. Год утверждения (DATE)
5. Описание учебного плана (TEXT прикрепляется файл)

Подробный учебный план:
1. ID (SMALLINT)
2. связь с учебным планом
3. связь с  предметом
4. связь с преподом
5. Номер курса (TINYINT)
6. Номер семестра (TINYINT)
7. Кол-во часов (SMALLINT)

Предмет:
1. ID (SMALLINT)
2. Название (NVARCHAR(40-50))
3. Описание (TEXT прикрепляется файл)

Оценки:
1. ID (SMALLINT)
2. Связь со студентом
3. Связь с подробным учебным планом
4. Название оценки (TINYINT)
5. Форма сдачи (NVARCHAR(40-50))
6. Дата сдачи (DATETIME)
