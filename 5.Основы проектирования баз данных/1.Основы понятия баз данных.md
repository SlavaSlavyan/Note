**Данные** - Это информация представленная в определённом виде, позволяющем автоматизировать её сбор, хранение и дальнейшую обработку человеком или информационным средством.

**База данных** - это совокупность данных, организованных по определённым правилам, предусматривающим общие принципы описания, хранения и манипулирования данными.

**СУБД** (система управления баз данных) - это комплекс программ, позволяющим создать базу данных и манипулировать данными (вставлять/обновлять/удалять/выделять).

**АИС** (автоматизированная информационная система) - это система, реализующая автоматизированный сбор, обработку и манипулирование данными.

**Банк данных** - является разновидность АИС. Это система специальным образом организованных данных (баз данных, программных, технических, языковых, методических средств) предназначенных для обеспечения централизованного накопления и коллективного многоцелевого использования данных.

**Модель баз данных** - способ структурирования данных в определённом виде, описание взаимосвязей между данными.

Модели баз данных:
1. Файловая модель.
	* Она характеризуется определённым набором файлов, не связанных между собой.
2. Иерархическая модель.
	* Эта модель представляет данные в виде иерархии. 
	* Модель ориентирована на описание объектов, находящихся между собой в отношении подчинения.
3. Сетевая модель.
	* Представляет собой развитие иерархической модели. 
	* Модель позволяет описывать более сложные виды взаимоотношений между данными.
4. Реляционная модель.
	* В реляционной модели данные представляются в виде таблиц, состоящие из строк и столбцов.
	* Каждая строка таблицы - это информация об одном конкретном объекте.
	* Столбцы содержат свойства этого объекта.
	* Взаимоотношения между объектами задаются с помощью связей между столбцами таблиц.
5. Гибридная модель.
	* В некоторых приложениях предпринимаются попытки смешения различных моделей
6. Объектно-ориентированная модель
	* Этот подход проектирования и разработки основан на концепции объектов и классов.
### Некоторые принципы проектирования БД

* Чёткое моделирование данных - это создание модели, которая точно отображает реальный сценарий.
* Нормализация - устранение избыточности, уменьшение аномалий и сохранение целостности данных.
* Создание осмысленных и согласованных соглашений об именах для сущностей, атрибутов и соглашений.
* Определение типов данных и ограничений - это выбор соответствующих типов данных и ограничений. и применение ограничений.
### Реляционные базы данных

БД основанные на реляционной модели называются **Реляционными базами данными**.

Основные понятия РБД;
* Сущность (таблица) - это представление набора реальных объектов (людей, товаров, вещей, событий, мест), которые имеют общие атрибуты или характеристики;
* Атрибут (поле) - это именованная характеристика, являющаяся некоторым свойством существа;
* Кортеж (записи/строки) - это каждая строка таблицы в которой хранятся данные разных типов.
* Связь (стрелочки) - это некоторая ассоциация между двумя сущностями. Одна сущность может быть связана с другой сущностью или с самой собой.
* Значение атрибута - это одно поле в таблице.

Популярные СУБД
1. MySQL
2. PostgreSQL
3. Microsoft SQL Server
4. Oracle
5. MongoDB
### Язык запросов

Для работы с БД используется язык SQL. У него присутствуют несколько диалектов, которые зависят от программ. С помощью SQL можно осуществлять различные операции в БД с информацией с помощью "запросов". С помощью запросов можно добавлять, изменять и удалять записи, а так же создавать, модифицировать и удалять таблицы.

Виды диалектов SQL в СУБД:
1. T-SQL (TransactSQL) - используется в СУБД Microsoft SQL Server.
2. PL/SQL (Procedural Language/SQL) - используется в СУБД Oracle.
3. SQL/PSM (SQL/Persistent Stored Module) - используется в СУБД MySQL.
4. PLpg/SQL (Procedual Language/postgreSQL) - используется в СУБД PostgreSQL.
5. SQLPL (SQL Prosedual Language) - используется в СУБД DB2
6. Jet SQL - используется в СУБД Microsoft Access.

**SQL** (Structured Query Language) - язык структурированных запросов.
