Среди многих попыток представить обработку данных на формальном абстрактном уровне, реляционная БД стала первой работоспособной моделью данных. Поскольку помимо средств описаний объектов имела эффективный инструментарий преобразований этих описаний это и будет называться операциями реляционной алгебры
Реляционная алгебра состоит из двух групп по 4 оператора
1. Традиционные операции
	1. объединение возвращает таблицу, содержащую все записи, которой принадлежат либо одной из двух заданных таблиц, либо им обоим(Как дизъюнкция в информатике) ![[Pasted image 20250916110714.png]]
	2. Пересечение возвращает таблицу, содержащую все записи, которые принадлежат одновременно обоим таблицам(Конъюнкция)![[Pasted image 20250916111420.png]]
	3. Разность возвращает таблицу, содержащую все записи, которые принадлежат первой таблице и не принадлежат второй![[Pasted image 20250916112213.png]]!![[Pasted image 20250916112914.png]]
	4. Произведение возвращает таблицу содержащую все возможные записи, которые являются сочетанием двух записей, принадлежащих соответственно двум заданным таблицам![[Pasted image 20250916113826.png]]
2. Специальные реляционные операции
	1. Выборка возвращает таблицу, содержащую все записи из заданной таблицы, которые удовлетворяют указанные условия![[Pasted image 20250916114635.png]]
	2. Проекция возвращает таблицу, содержащую все записи заданной таблицы, которые остались в этой таблице после исключения некоторых атрибутов
		![[Pasted image 20250916115146.png]]
	3. Соединение возвращает таблицу, содержащую все возможные записи, которые представляют собой комбинацию атрибутов двух записей, принадлежащим двум заданным таблицам, при условии, что в этих двух комбинированных записях присутствуют одинаковые значения(первичный и вторичный ключ)![[Pasted image 20250916120324.png]]
	4. Деление для заданных двух таблиц и одной бинарной возвращает таблицу, содержащую все записи из первой таблицы, в которой содержит также бинарные таблицы и соответствует всем записям во второй таблице. Объяснение: преподаватель с ID 2 ведет все курсы, преподаватель 1 не ведет 103 курс, соответственно не все записи выполнены из второй таблицы![[Pasted image 20250916120924.png]]
