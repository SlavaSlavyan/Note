## Логика

При первом взгляде вам может быть непонятно где вообще находятся мои фалы, но тут всё логично. Все задания мы выполняем в определённые дни. Все ДЗ в системе колледжа так же имеют дату. Каждая папка с файлами - это и есть число

*то есть 220426 - это 22 апреля 2026 года*

В этих папках находятся одельные папки task с нумерацией от единицы. Тут думаю ничего сложного, у каждого задания есть свой номер (￣y▽,￣)╭ 

Если задание умещается в один файл, то в папке обычно будут находится **3 основных файла**:

- **code.cpp** (чистый код)
- **build.exe** (исполняемый exe файл для простого запуска)
- **readme.md** (само задание)

Иначе, задание разбивается на дополнительные обьекты

- **readme.md** (задание)
- **build.exe** (исполняемый exe файл для простого запуска)
- **start.cpp** (точка входа)
- **include/** (файлы заголовки с разширением .hpp или .h)
- **src/** (доп файлы с расширением .cpp)

В папке конечно могут быть и другие файлы и если они будут появляться я это обязательно укажу :D
