# Практика по работе с классом string

## Задача 1: Приветствие и знакомство с .length() и .at()

### Условие: Напишите программу, которая:

1. Объявляет строковую переменную **name** и инициализирует её вашим именем.
2. Выводит на экран сообщение: **"Привет, \<имя>!"** .
3. Выводит на экран длину строки **name**, используя метод **.length()**.
4. Выводит на экран первый символ строки, используя метод **.at(0)**.

### Ожидаемый результат (пример для имени "Анна"):

```text
Привет, Анна!
Длина имени: 4
Первый символ: А
```

**Проверяемые методы:** Конструктор **string , cout , .length() , .at()**.

Затем программа должна поприветствовать пользователя и создать строку **greeting**, которая является результатом конкатенации (сложения) строк **"Добрый день, "** и введённого имени. Выведите итоговое приветствие на экран.

### Пример диалога:

**Условие**: Пользователь вводит строку, состоящую из нескольких слов в нижнем регистре (например, **"программирование на c++"**). Напишите программу, которая преобразует эту строку так, чтобы первая буква каждого слова стала заглавной. Остальные буквы должны остаться в нижнем регистре.

