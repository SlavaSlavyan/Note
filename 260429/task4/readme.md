# Задача 4: «Банковский счёт» (Инкапсуляция + Конструктор с проверками) 

### Условие: 

Создайте класс **BankAccount**, моделирующий банковский счёт. Доступ к балансу должен быть закрытым, а все операции — контролируемыми.

### Задание: 

1. Создайте класс **BankAccount** со скрытыми ( **private** ) полями: 

    - **char\* owner** — имя владельца 
    - **int accountNumber** — номер счёта 
    - **double balance** — баланс 

2. Реализуйте публичный конструктор с параметрами: В конструкторе: 

    - Выделите память и скопируйте имя владельца через **strcpy_s** 
    - Проверьте, что **initialBalance** не отрицательный; если отрицательный — установите баланс в 0 и выведите предупреждение 

3. Реализуйте публичные методы: 

    - **void deposit(double amount)** — пополнить счёт (сумма должна быть положительной, иначе — вывести ошибку)
    - **bool withdraw(double amount)** — снять деньги (если сумма > баланса — вернуть **false** и вывести ошибку; иначе списать и вернуть **true**) 
    - **double getBalance()** — вернуть текущий баланс
    - **void printInfo()** — вывести в формате: 
        - Владелец: \<owner> 
        - Счёт №: \<accountNumber> 
        - Баланс: \<balance> руб.

4. Не забудьте про деструктор для освобождения памяти. 

5. В **main()** проверьте все методы, включая попытку снять больше, чем есть 
на счету.
