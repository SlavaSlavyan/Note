# Задача 3: «Веб-ссылка» (Конструкторы: инициализацияобъекта)

### Условие:

Разработайте класс **WebLink** для хранения URL-адреса и его описания. Объект должен создаваться уже с заполненными данными, чтобы избежать хранения неопределённых значений.

### Задание:

1. Создайте класс **WebLink**, который инкапсулирует данные о ссылке в закрытых ( **private** ) полях: **char\* url** и **char\* description** (потребуется ручное управление памятью, как в примере из урока).

2. Реализуйте публичный конструктор с параметрами: **WebLink(const char\* linkUrl, const char\* linkDesc)** В теле конструктора выделите память в куче (с помощью **new**) и скопируйте строки(**strcpy_s** или в цикле) из параметров **linkUrl** и **linkDesc** в поля **url** и **description**.

3. В публичной секции реализуйте метод-инспектор **void print()** для вывода информации о ссылке в формате:

    - **Описание: \<description>**
    - **Адрес: \<url>**
    
4. В функции **main** создайте объект класса **WebLink** одной строкой: 

``` cpp
WebLink mySite("https://academy.top", "Сайт Компьютерной Академии");
```

и вызовите для него метод **print()**.
