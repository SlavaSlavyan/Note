# Задача 2: «Лампочка с выключателем» (Инкапсуляция: private, аксессоры и мутаторы)

### Условие:

Создайте класс **LightBulb**, моделирующий работу лампочки. Прямой доступ к её внутреннему состоянию должен быть запрещён согласно принципу инкапсуляции.

### Задание:

1. Создайте класс **LightBulb** со скрытой ( **private** ) переменной-членом **bool** **isOn**, которая хранит состояние лампочки (вкл./выкл.).

2. В открытой ( **public** ) секции реализуйте методы-модификаторы (мутаторы) для управления лампочкой:

    - **void turnOn()** — включает лампочку (устанавливает **isOn** в **true**) 
    - **void turnOff()** — выключает лампочку (устанавливает **isOn** в **false** ).
    - **void toggle()** — переключает состояние лампочки на противоположное.

3. В открытой секции реализуйте метод-инспектор (аксессор) для получения состояния лампочки:

    - **const char\* getState()** — возвращает строку **"ON"** , если лампочка включена, и **"OFF"**, если выключена.

4. В функции **main** создайте объект **LightBulb**, вызовите несколько раз методы **turnOn**, **toggle** , **turnOff** и после каждого изменения состояния выводите в консоль текущее состояние лампочки с помощью **getState()**.
