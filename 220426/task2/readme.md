# Задание 2. Класс «Банковский счет»
### Условие
Создайте класс BankAccount, который содержит:
- Закрытые поля:
    - accountNumber — номер счета.
    - balance — баланс счета.
    - ownerName — владелец счета.
- Конструктор, принимающий номер счета, имя владельца и начальный баланс (по умолчанию 0).
- Свойства:
    - AccountNumber — только чтение.
    - OwnerName — чтение и запись.
    - Balance — только чтение.
- Методы:
    - Deposit(decimal amount) — пополнение счета (сумма должна быть положительной).
    - Withdraw(decimal amount) — снятие средств (сумма не может превышать баланс).
    - DisplayInfo() — вывод информации о счете
