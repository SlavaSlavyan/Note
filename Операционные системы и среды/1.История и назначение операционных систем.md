**ЭВМ** (электронно-вычислительная машина) - это аппаратно-программное вычислительное устройство, реализованное на электронных компонентах, и выполняющее заданное программой действие - **Персональный компьютер**.

**Операционная система** - это набор программ, обеспечивающих работу компьютера или другого устройства и взаимодействие с ним пользователя.

**ОС** работает как посредник между пользователем и аппаратным обеспечением - процессором, оперативной памятью, клавиатурой, компьютерной мышью и другими компонентами.

ОС решает 2 взаимодополняющие задачи:
* Предоставление набора функций с целью создания удобной среды для работы пользователя;
* Организует процесс работы множества приложений на одном ЭВМ, защищая приложения друг от друга и распределяя ресурсы ЭВМ;

Функции ОС:
1. Управление процессами:
	* ОС решает какие выделить ресурсы для определённых приложений;
2. Управление памятью:
	* ОС управляет оперативной памятью компьютера, организуя выделение памяти и следит за эффективностью её использования;
3. Управление файлами и файловыми системами:
	* ОС использует файловые системы, которые определяют структура хранения и организации данных на диске;
	* ОС предоставляет интерфейс для работы с файлами;
4. Управление устройствами ввода и вывода:
	* ОС управляет всеми периферийными устройствами:
		* клавиатура;
		* мышь;
		* принтер;
		* микрофон;
		* колонки;
		* наушники;
		* джойстик;
		* веб-камера;
		* монитор;
	* ОС использует механизм драйверов, который обеспечивает взаимодействие между устройствами и ОС;
5. Безопасность и защита:
	* ОС обеспечивает безопасность данных и пользователей через механизмы аутентификации и авторизации.

3 обязательные составляющие ОС:
1. Ядро (командный интерпретатор) - переводчик с программного языка на язык машинных кодов;
2. Специализированные программы, называемыми драйверами, предназначенными для управления различными устройствами;
3. Системная оболочка, с которой общается пользователь (интерфейс).
### Что представляет ПК без ОС?

Компьютер **может работать без ОС**, но универсальность устройства не достигается. Без ОС компьютер может выполнять некоторые задачи, но сложные задачи для него не выполнимы.

Функции ПК без ОС:
* Запуск программы напрямую;
* Выполнение простых функций;
* Запуск программ созданных для работы на голом железе.

Ограничения ПК без ОС:
* Однозадачность - без ОС компьютер может выполнять только 1 программу за раз;
* Сложности с распределением ресурсов;
* Проблема с драйверами - без ОС в программе должны быть встроены драйвера;

Примеры ЭВМ без ОС:
1. Первые персональные компьютеры;
2. Чистые ноутбуки

**BIOS** (базовая система ввода и вывода) - это встроенное программное обеспечение на материнской плате компьютера. Он находится в чипе памяти, запаянной в материнской плате, и работает независимо от жёсткого диска и ОС.
В современных компьютерах BIOS часто заменён на UEFI.

UEFI (универсальный расширяемый встроенный интерфейс) - это улучшенная версия BIOS с графическим интерфейсом.
### История развития ОС

Этапы развития ОС:
1. Первые вычислительные машины (1940-е - 1950-е гг.):
	* Они выполняли с помощью *перфокарт и перфолент*;
	* Перфокарты и перфоленты - это термины которые относятся к носителям информации с перфорациями (отверстия круглой или прямоугольной формы), места расположения которых соответствуют закодированной информации;
	* Именно на этом этапе родилась идея об **операционной системе**.
2. Многозадачность и развитие первых операционных систем (1960-е гг.):
	* Появление первых многозадачных ОС было связано с развитием вычислительных машин и появления *транзисторов*;
	* Транзистор - полупроводниковый прибор, который управляет электрическим током с помощью электрического сигнала;
	* Одной из первых ОС, использующая принцип многозадачности, была CTSS. Она предлагала как разделение времени, так и пакетную обработку одновременно;
	* Разделение времени в ОС - это принцип работы, при котором машинное время распределяется между несколькими выполняющимися задачами;
	* Пакетная обработка - это метод обработки данных большими порциями в запланированные интервалы времени;
3. Системы с разделением времени (1970-е гг.):
	* В это время была создана ОС такая как **UNIX**. Она была революционной для того времени, а сейчас это *"Золотой стандарт"*, по которому развивается большинство систем. Так же UNIX дала возможность работы множеству пользователей одновременно;
4. Персональные компьютеры, графические интерфейсы (1980-е - 1990-е гг.):
	* С развитием ПК появился рынок ОС для домашних пользователей;
	* Компания Microsoft впервые предоставляет свою графическую оболочку *Windows*, которая в последствии завоевала популярность и используется до сих пор;
5. Современные операционные системы(2000-е и далее):
	* ОС претерпела значительные изменения, связанные с ростом мобильных устройств, а так же с увеличением требуемых возможностей для облачных вычислений и виртуализации;
	* Крупнейшими ОС стали:
		* Windows
		* Linux
		* MacOS
		* Android
		* IOS

### Основная классификация ОС

1. По числу выполняемых задач:
	* однозадачные;
	* многозадачные;
2. По числу одновременно работающих пользователей:
	* однопользовательские;
	* многопользовательские;
3. По реализации интерфейса пользователя:
	* графические;
	* не графические;
4. По числу процессоров:
	* однопроцессорные;
	* многопроцессорные;
5. По разрядности кода (сколько бит информации процессор может обработать за одни раз):
	* 8-разрядные;
	* 16-разрядные;
	* 32-разрядные;
	* 64-разрядные;
6. По числу выделяемых потоков при решении задач:
	- Одно потоковые;
	- Много потоковые (когда система разбивает одну задачу на несколько потоков и выполняет их, независимо друг от друга);
7. По возможности управления сетевыми ресурсами:
	* локальные;
	* сетевые;
8. По типу лицензии:
	- проприетарная (собственная/закрытая);
	- свободная или открытая;
9. По типу устройства:
	* Десктопные;
	* Мобильные;
	* Встроенные (спец устройства);
10. По типу архитектуры:
	- Монолитные (все основные компоненты ОС работают в одном пространстве, и не могу быть без друг-друга)
	- Модульные (система состоит из набора независимых компонентов, которые могут быть загружены и удалены по мере необходимости)
